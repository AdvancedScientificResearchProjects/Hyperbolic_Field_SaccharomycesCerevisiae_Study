# Исследование Влияния Гиперболических Полей на Saccharomyces cerevisiae — Хаб Просмотра Данных

Экспериментальные наборы данных, изображения микроскопии и аналитические материалы по воздействию
излучателей гиперболических полей на *Saccharomyces cerevisiae*. Включает необработанные поля
микроскопии, идентификацию образцов по журнальной разметке, CV и LLM анализ плотности, и ссылки
на протоколы.

---

## Как просматривать данные

1. **Выберите группу условий** → таблица ниже; каждая строка определяет канал, среду, цикл и увеличение
2. **Найдите номера изображений** → используйте [Спецификацию IMG-нумерации / Sample-ID](#спецификация-img-нумерации--sample-id) ниже, чтобы сопоставить `IMG_XXXX` с каналом / средой / циклом / зоной через `journal-mapping.csv`
3. **Просматривайте JPEG-превью** → `data/photos/jpg/` — 972 JPEG-файла для просмотра в браузере; оригиналы (HEIC/PNG) в `data/photos/original/`
4. **Читайте отчёт по плотности** → `reports/2026-06-09_density-analysis/report_ru.md` — триангулированный CV + LLM анализ по всем 972 полям
5. **Машинно-читаемые метаданные** → `data/photos/manifest.json`; журнальная разметка → `data/photos/journal-mapping.csv`

## Спецификация IMG-нумерации / Sample-ID

**Формат:** `IMG_XXXX`, где XXXX — 4-значный порядковый номер камеры iPhone.

**Источник разметки:** `../data/photos/journal-mapping.csv`
(используйте `.verified.csv` — не черновик; верифицированный файл — авторитетная разметка.)

**Декодирование номера изображения:**

1. Откройте `journal-mapping.csv`.
2. Найдите строку, где `img_start <= XXXX <= img_end` (с учётом известных пропусков, указанных в колонке `notes`).
3. Считайте `channel`, `exposure` (среда: N или P), `set` (цикл: 1/2/3), `zone` (белый = 100×, жёлтый = 10×, или `—` для сета 1).
4. Поле `group_id` даёт полный составной ключ, например `S2-ch17-N1-b` = сет 2, канал 17, нейтральная среда, реплика 1, зона белый.

**Семантика ключевых полей (подтверждено руководителем 2026-06-09):**

| Поле журнала | Значение |
|---|---|
| `channel 0` | Контроль — воздействие поля отсутствует |
| `channel 17` | Конфигурация гиперболического поля CH17 (по протоколу «неизвестен»; наблюдалась наибольшая плотность) |
| `channel 19` | Конфигурация гиперболического поля CH19 — «ускорение» |
| `channel 21` | Конфигурация гиперболического поля CH21 — «замедление» |
| `exposure N` | Нейтральная среда роста (нейтральный раствор) |
| `exposure P` | Питательная среда роста (питательный раствор) |
| `set 1 / 2 / 3` | Цикл эксперимента (биологическая реплицированная партия) |
| `zone белый` | Увеличение 100× (белое кольцо объектива) |
| `zone жёлтый` | Увеличение 10× (жёлтое кольцо объектива) |
| `zone —` | Только сет 001 — разделения на увеличения не записано |

**Известные аномалии в последовательности изображений (из верифицированного журнала):**

- `IMG_4819`: зачёркнут в журнале (считать отменённым; 4820 — фактически первый из S1-ch0-P1)
- `IMG_4847`: зачёркнут как разделитель блока; файл есть на диске, но вне любой группы разметки
- `IMG_4857`: отсутствует на диске (пропуск в S1-ch17-P2)
- `IMG_4868`: есть на диске, но незалогирован (S1-ch17-P2 в журнале его пропускает)
- `IMG_4941`: отсутствует на диске (пропуск в S1-ch21-P1, подтверждён диском)
- `IMG_4971`: отсутствует (пропуск в S1-ch21-N2 по журналу)
- `IMG_4988`: отменён/зачёркнут в журнале; PNG-файл на диске — микроскопия, не полевой кадр
- `IMG_5090`, `IMG_5142`, `IMG_5657`: есть на диске, задокументированные незалогированные одиночные кадры

## Предварительные ключевые результаты (2026-06-09)

Анализ первого пакета снимков (972 поля микроскопии, циклы 001–003) тремя независимыми методами
(CV счёт клеток при 100×, CV занятость, слепой LLM) дал воспроизводимый направленный сигнал:

| Канал | Счёт клеток при 100× | к контролю | Ранг занятости (циклы 2–3) |
|:---:|:---:|:---:|:---:|
| CH0 (контроль) | 112 | — | средн. |
| **CH17** | **205** | **+83%** | **1-й (плотнейший, все методы)** |
| CH19 | 118 | +5% | 2-й |
| **CH21** | **88** | **−21%** | **4-й (ниже контроля, все методы)** |

CH19 — не нулевой результат: его эффект кинетический/морфологический — клетки примерно на 7% меньше по площади (p ≈ 2,6×10⁻⁴ описательный). **Предварительно зарегистрированная роль CH19 (гипотеза) — ускорение темпа деления / динамики, а НЕ увеличение биомассы или числа клеток** (счёт ≈ контроль — ожидаемый результат; увеличение числа клеток относится к CH17). На данной статичной конечной точке клетки примерно на 7% меньше по площади, но не более удлинены, а почкование плоское — гипотеза о темпе деления требует дальнейшей проверки методами time-lapse / OD600 (см. report §9).

Согласие методов по кадрам (Спирмен): счёт ↔ занятость ρ = 0,88; занятость ↔ LLM ρ = 0,89; счёт ↔ LLM ρ = 0,81.

> **Оговорка:** Предварительно — только 3 цикла; цикл 1 не согласуется с порядком; p-значения только описательные

## Связанные исследования

**Сопутствующее исследование — Гиперболическое поле: Исследование Плазмы Крови**

Исследование плазмы крови является непосредственным предшественником настоящего репо и источником канальных прецедентов, использованных в H3. В нём тестировалась та же конфигурация каналов CH17/CH19/CH21 на свёртываемость плазмы крови человека. CH19 вызывал быстрое образование сгустка + лизис (поведение ускорения времени); CH21 давал плотный, медленный сгусток (замедление времени). Эти наблюдения легли в основу направленных гипотез, перенесённых в дрожжевую систему.
