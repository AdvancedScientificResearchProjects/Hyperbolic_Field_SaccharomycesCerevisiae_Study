# Реакция плотности клеток дрожжей на воздействие гиперболического поля: триангулированный анализ изображений

**🌐 Language / Язык:** [English](report_en.md) · **Русский**

**Дата**: 2026-06-09
**Датасет**: 990 полей микроскопии (972 снимка окуляра в формате HEIC + 18 цифровых снимков PNG), *Saccharomyces cerevisiae*
**Условия**: контроль (CH0) + каналы гиперболического поля CH17 / CH19 / CH21; нейтральный (N) и питательный (P) раствор; 3 цикла эксперимента; увеличения 10× и 100×
**Статус**: Предварительный сигнал — не подтверждающий (см. §8)
**Версия:** v2 (2026-06-09)
**Метод:** Cellpose cyto2 (cellpose 3.x, diameter=18) + текстурная занятость без сегментации + слепая LLM-оценка зрением
**Аналитическая система:** Claude Opus 4.8 (`claude-opus-4-8`) — слепая оценка зрением по каждому полю; Cellpose cyto2 — CV-сегментация/счёт клеток

> **UPD v2 (2026-06-09):** Трактовка CH19 исправлена — значение ≈ контроль по счёту является *ожидаемым* результатом (предполагаемый эффект CH19 морфологический/кинетический, см. §9); морфометрическое продолжение показывает, что клетки CH19 имеют площадь примерно на 7,6 % меньше, но **не** более вытянуты (если что — скорее круглее), поэтому предсказание о более тонких клетках / ускоренном делении на данной конечной партии **не подтверждается**. Смена знака в цикле 1 задокументирована (§4.3).

## 1. Мотивация

Исследование ставит вопрос: изменяет ли воздействие гиперболического поля динамику деления *S. cerevisiae*? Протокольные гипотезы предсказывают, что CH19 ускоряет, а CH21 замедляет деление относительно контроля; для CH17 прогноз a priori отсутствует. Эти предсказания по каналам происходят из родственного исследования ASRP **Hyperbolic Field Blood Plasma Study** (OSF: osf.io/8q42f, DOI 10.17605/OSF.IO/GWA9E), где CH19 = ускорение времени, а CH21 = замедление времени. В данном отчёте анализируется первая крупная партия микроскопии (циклы 001–003) тремя независимыми методами анализа изображений; основной вопрос: **различается ли плотность клеток по каналам и согласуются ли методы между собой?**

Лабораторный журнал (рукописный, три страницы) сопоставляет каждый номер снимка IMG_XXXX с каналом × раствором × репликатом × увеличением; разметка была расшифрована и перекрёстно проверена (многопроходная проверка + наличие файлов на диске + два якорных элемента) с покрытием 99,5 %. Семантика меток была подтверждена непосредственно исследователем (В.): **N = нейтральный раствор, P = питательный раствор; наборы 001/002/003 = циклы эксперимента; зоны белый/жёлтый = увеличение 100×/10×; группа 2-0-P1 выбыла (пролита); жизнеспособность не окрашивалась (синий оттенок — это раствор/освещение)**.

(Числа полей по каналам в таблице отражают 920 полей, оценённых LLM; для одного поля CH19 оценка равна null и выпадает из медианы §5, откуда CH19 n=250 против 251 здесь.)

### 2.2. Структура репликатов

Единицей репликации является **цикл эксперимента** (набор 001/002/003), а не отдельный снимок. Несколько полей из одного цикла являются техническими субвыборками (псевдорепликаты — множество снимков одной чашки Петри считаются независимыми наблюдениями, что искусственно завышает размер выборки). Сила доказательной базы определяется **согласованностью между циклами**, а не p-значениями по отдельным полям. Примечание: метрика **счёта** cyto2 существует только для полей 100×, которые присутствуют **только в циклах 2 и 3** → эффект по счёту охватывает N=2 цикла (не проверяется на уровне репликатов); занятость охватывает все три цикла.

### 2.3. Методы анализа (три метода измерения)

1. **Счёт клеток CV (cyto2)** — инстанционная сегментация Cellpose `cyto2`, диаметр откалиброван по клеткам (≈18 пикс. при уменьшении до 1100 пикс.). Применим только при **100×**, где клетки разрешены; бессмысленен при 10× (слитные газоны из субразрешённых клеток).
2. **Занятость/текстурная плотность CV** (занятость = доля площади изображения, занятая клетками; 0 = пусто, 1 = полностью) — без сегментации: локальная текстурная энергия + занятость по Отсу + плотность краёв внутри поля зрения. Устойчив к неоднородности размеров в датасете (разреженные поля И газоны); применён ко **всем 972 полям**.
3. **Слепая LLM-оценка** — один независимый проход LLM-зрения на поле, нейтральные имена файлов, условие не раскрывалось; оценка плотности / счёта клеток / почкования / распределения по каждому полю. Оценено 920 полей.

Все три метода **агностичны к группе**: канал раскрывается только на этапе агрегации. Методы **независимы алгоритмически, но не независимы наблюдательно** — два метода CV работают на идентичных пикселях, поэтому межметодное согласие защищает от *алгоритмического* артефакта, но не от общего *конфаунда съёмки* (фокус, разведение, сессия).

### 2.4. Подтверждённая семантика меток

| белый / жёлтый | Увеличение микроскопа 100× / 10× |

| Цикл | CH0 | CH17 | CH19 | CH21 |
|---|:---:|:---:|:---:|:---:|

CH17 занимает #1, а CH21 — #4 в **обоих** циклах 2 и 3 (средний ранг 1.00 / 4.00). Следует отметить, что метрика счёта охватывает здесь **только циклы 2–3** (в цикле 1 нет разделения по увеличению 100× → счёт отсутствует), поэтому эффект по счёту охватывает **N=2 цикла**.

**Цикл 1 активно инвертирует эффект.** В цикле 1 (занятость — единственная доступная там метрика) **CH21 является самым плотным каналом (0.246, +74 % vs контроль 0.141), а CH17 занимает лишь 2-е место** — инвертируя оба ключевых утверждения. Инверсия устойчива внутри цикла 1 (подтверждается по всем трём метрикам плотности CV; P(CH21 > CH0) по полям ≈ 81–83 %), то есть это настоящая смена знака, а не выброс. Оговорка действует в обоих направлениях: цикл 1 использовал **иной протокол съёмки** (n=24 контрольных поля, абсолютная занятость ≈0.14 против ≈0.45 в циклах 2–3), что само по себе ограничивает его сопоставимость. Итог: **2 из 3 циклов поддерживают порядок CH17↑/CH21↓; 1 из 3 ему противоречит (знак инвертирован).**

**Примечание по CH19:** метрика счёта **не является тестом для CH19**. Протокольное утверждение CH19 носит кинетический/морфологический характер (скорость деления + форма клеток), поэтому CH19 ≈ CH0 по счёту — это *ожидаемый* результат, а **не** свидетельство против гипотезы CH19; эта гипотеза оценивается по морфометрии (§9), а не по счёту.

## 6. Согласованность методов

Коэффициенты корреляции Спирмена (ρ = корреляция Спирмена; число от −1 до +1, показывающее, насколько согласованно два метода ранжируют одни и те же поля; 1 = полное совпадение, 0 = нет связи) между тремя независимыми измерениями попарно, по полям:

| Пара методов | Увеличение | ρ | n |
|---|:---:|:---:|:---:|
| счёт cyto2 ↔ занятость | 100× | **0.88** | 398 |
| занятость ↔ LLM | 100× | **0.89** | 376 |
| счёт cyto2 ↔ LLM | 100× | **0.81** | 376 |
| занятость ↔ LLM | 10× | 0.62 | 370 |

![Согласование CV и LLM, 100×](https://raw.githubusercontent.com/AdvancedScientificResearchProjects/Hyperbolic_Field_SaccharomycesCerevisiae_Study/main/reports/2026-06-09_density-analysis/charts/chart_cv_vs_llm.png)

**Вывод**: при 100× все три метода хорошо согласуются попарно (ρ = 0.81–0.89), а два метода CV согласуются между собой (ρ = 0.88) — сигнал не является артефактом одного алгоритма. При 10× согласованность снижается (ρ = 0.62), поскольку слитные газоны физически трудно квантифицировать как подсчётом, так и визуально; только прокси занятости является здесь надёжным.

### 6.1 Реален ли сигнал CH17/CH21 или это случайность?

**Аргументы за (реален):**
- CH17↑ / CH21↓ согласуются по всем **трём методам измерения** (счёт cyto2, занятость, слепая LLM).
- Порядок сохраняется при **обоих увеличениях** (100× и 10×).
- Он сохраняется в **обоих циклах 2 и 3** (CH17 — ранг #1, CH21 — ранг #4 в каждом).
- Попарное согласие методов по полям высокое: ρ = 0.81–0.89.
- Эффект **упорядочен по дозе** (монотонен по каналам).
- **Слепая LLM** воспроизводит тот же порядок независимо от конвейера CV.

**Аргументы против (может быть случайностью/артефактом):**
- **Псевдорепликация**: данные счёта несут лишь ~2 биологических репликата; p-значения описательные, не инференциальные.
- **Цикл 1 активно инвертирует порядок** (CH21 наиболее плотный, +74 % vs контроль).
- Эффект по счёту опирается лишь на **N=2 цикла**.
- Два метода CV **работают на одних и тех же пикселях** — общий конфаунд съёмки (фокус, разведение, сессия) не исключён.
- cyto2 **недосчитывает ~40 %** в плотных полях.
- **Нет масштабной линейки** — плотности только относительные.

**Вывод:** реальный, воспроизводимый *направленный* сигнал в циклах 2–3 — но **предварительный, не подтверждающий**. Для подтверждения необходимо ≥5 циклов в рамках единого протокола съёмки.

## 8. Ограничения

1. **Репликация**: только 3 цикла эксперимента; чистый сигнал наблюдается в циклах 2–3, но **цикл 1 ему противоречит** (иной протокол съёмки — без разделения по увеличению). Для подтверждающего заключения необходимо ≥5 циклов.
2. **Псевдорепликация**: p-значения по отдельным полям (Краскел–Уоллис p < 1e-4) завышены, поскольку поля внутри одного цикла не независимы. Они приводятся исключительно как описательные; реальное свидетельство — это согласованность между циклами, увеличениями и методами.
3. **Отсутствие масштабной линейки**: плотности являются относительными (клеток на поле, доля занятости), а не клеток/мл или мкм.
4. **Систематический недосчёт**: cyto2 пропускает ≈40 % клеток в плотных полях, но систематически — относительное сравнение каналов сохраняет силу; абсолютные значения счёта — нет.
5. **Возможные систематические ошибки съёмки по каналам** (фокус, разведение, сессия) полностью не исключены; оба метода CV работают на одних и тех же пикселях, поэтому они не контролируют этот конфаунд.
6. **Отсутствие оценки жизнеспособности**: в данной партии жизненный краситель не применялся (подтверждено), поэтому доля живых/мёртвых клеток здесь не оценивается.
7. **Цикл 1 инвертирует эффект** (CH21 там наиболее плотный): порядок подтверждается в 2 из 3 циклов и активно опровергается в третьем — см. §4.3. Ключевой результат по счёту (+83 %/−21 %) опирается только на 2 цикла, в которых имеются данные 100×.
8. **Кинетическая гипотеза CH19 не проверяема по статичным конечным точкам** (конечная точка = одиночный снимок, сделанный в один момент времени, который не показывает, как клетки менялись во времени); требует времени удвоения OD600 + тайм-лапс (см. §9).

## 9. Заключение

**CH17** обеспечивает наибольшую плотность клеток в циклах 2–3 — ≈ 1.6–1.8× контроля по счёту клеток, воспроизведено при обоих увеличениях и подтверждено слепой LLM-оценкой. Будучи a priori «неизвестным», CH17 выступает наиболее выраженным стимулятором роста **в этих двух циклах**.

**CH21** обеспечивает наименьшую плотность в циклах 2–3 — устойчиво **ниже** контроля (−21 % по счёту), что соответствует протокольному предсказанию о замедлении деления. **Однако цикл 1 инвертирует это** (CH21 там наиболее плотный, +74 % vs контроль), поэтому эффект CH21 пока не является воспроизводимым во всех циклах.

**CH19** не обнаруживает изменений числа клеток по сравнению с контролем — это **ожидаемый** результат, а не нулевая находка. Гипотеза протокола CH19 носит **кинетический/морфологический** характер (более быстрое деление, более тонкие/вытянутые клетки), а не предполагает увеличения плотности, поэтому счёт клеток является неверной осью для её проверки. При прямой проверке морфологической оси (форма отдельных клеток по маскам cyto2, 100×): клетки CH19 имеют **среднюю площадь примерно на 7,6 % меньше**, чем у контроля (n=110 vs 82, p ≈ 6e-5 (= 0,00006; вероятность того, что различие — чистая случайность; чем меньше, тем сильнее), описательно (p приводится только для оценки масштаба и направления, а не как формальная проверка значимости, поскольку выборки не независимы — см. псевдорепликация)) — но это **не специфично для CH19** (CH17 −12,7 %, CH21 −6,1 %; каждый канал поля меньше контроля), поэтому одна лишь площадь клетки не выделяет эффект CH19. По дискриминирующей метрике формы — эксцентриситет (мера вытянутости клетки от 0 до 1; 0 = идеальный круг, 1 = линия) / соотношение главной и малой осей (отношение длиннейшего диаметра клетки к кратчайшему; 1,0 = круг, больше = вытянутее) — CH19 **не более вытянут**: эксцентриситет незначительно *ниже* контроля (0.544 vs 0.560, p = 0.039), а соотношение осей не меняется (1.246 vs 1.256, н.з. (статистически незначимо — слишком мало, чтобы исключить случайность)) — то есть, если что, доля **круглее, а не тоньше**, что *противоположно* предсказанию, и эффект крошечный (Δ ecc ≈ 0.016). Прокси скорости деления (почкование — доля дрожжевых клеток, активно делящихся, что видно как небольшая почка на материнской клетке) также **не меняется** (LLM Δ ≈ −0,01 по шкале 0–3, n=104; солидность cyto2 0.023 vs 0.016). **Вывод по CH19:** нейтрален по счёту, как и ожидалось, но на данном конечном наборе данных **не подтверждается ни предсказание о более тонких/вытянутых клетках, ни ускоренное деление**. Корректная проверка требует **тайм-лапс-протокола** (скорость деления неизмерима по статичным полям) и специализированной морфометрии по отдельным клеткам — отмечена как приоритетное продолжение.

**Биологический контекст и как корректно проверить CH19.** Протокольное предсказание по CH19 — ускоренное деление, дающее более мелкие клетки без увеличения биомассы/счёта — биологически связно: у почкующихся дрожжей механизм Whi5/G1-сайзера означает, что ускоренное прохождение Start даёт более мелкие дочерние клетки (Di Talia 2007; Jorgensen & Tyers 2004), а скорость деления может быть отвязана от накопления биомассы (Schmidt-Glenewinkel & Barkai 2014), поэтому «более быстрое деление при том же счёте/биомассе» — допустимый сценарий. Однако наше сокращение площади на ~7,6 % **согласуется с более быстрым делением, но не является его диагностическим признаком** — сопоставимое уменьшение возникает из-за неконтролируемых нами конфаундов, в частности гибнущих клеток / клеток стационарной фазы (≈27 % потери площади; Kato 2021), ограничения по питательным веществам или повышенной доли покоящихся клеток. Доля почкования по одной временной точке (наша LLM-оценка почкования) также не позволяет отделить «более быстрое деление» от «остановки в G2/M». **Минимальный эксперимент для реальной проверки CH19:** сравнение времени удвоения по кривой роста OD600 (золотой стандарт для скорости деления), плюс временной ход индекса почкования в экспоненциальной фазе и окрашивание на жизнеспособность для исключения конфаунда гибнущих клеток; тайм-лапс-микроскопия подтвердила бы это на уровне отдельных клеток.

**Совокупное свидетельство**: три метода измерения согласуются попарно по полям (ρ = 0.81–0.89) и по порядку каналов (CH17 ↑, CH21 ↓) в **2 из 3 циклов** и при обоих увеличениях; **в третьем цикле порядок активно инвертируется**. Это **направленный сигнал в циклах 2–3, но ещё не воспроизводимый эффект** — он опирается на 3 цикла (только 2 с данными счёта), один из которых противоречит результатам, и требует ≥5 циклов в рамках единого протокола съёмки для подтверждения. Методы алгоритмически независимы, но работают на одних и тех же изображениях, поэтому общий конфаунд съёмки не исключён.

## Глоссарий

Простое объяснение технических терминов, используемых в этом отчёте.

| Термин | Простое объяснение |
|---|---|
| н.з. | Незначимо / статистически не значимо — различие между группами слишком мало, чтобы исключить случайность. |
| p / p-значение | Число от 0 до 1: вероятность того, что наблюдаемое различие возникло случайно. p < 0,05 = менее 5% вероятности случайности. Запись 6e-5 = 0,00006 (очень мало = крайне маловероятна случайность). |
| описательное (p-значение) | p приводится только для справки о масштабе/направлении, а не как формальная проверка значимости — допущение о независимости выборок нарушено (см. псевдорепликация). |
| ρ (ро) / корреляция Спирмена | Число от −1 до +1, показывающее согласованность ранжирования полей двумя методами. ρ = 0,88 = очень высокое согласие (методы почти всегда дают одинаковый ранг по числу клеток). |
| псевдорепликация | Несколько снимков одной чашки Петри считаются независимыми наблюдениями. Завышает выборку и занижает p. Настоящие репликаты здесь — циклы эксперимента (всего 3), а не отдельные снимки. |
| Краскел–Уоллис | Статистический тест для сравнения 3 и более групп без допущения о нормальном (колоколообразном) распределении. Здесь — проверка различия счёта клеток по каналам. |
| SEM | Стандартная ошибка среднего — мера точности оценки среднего (меньше = точнее). |
| N=2 цикла | Результат по счёту клеток опирается лишь на 2 независимых повторения эксперимента; слишком мало для статистической проверки на уровне цикла. |
| Δ (дельта) | Разность двух значений. Δ ecc = 0,016 — эксцентриситет отличается на 0,016 единицы. |
| cyto2 / Cellpose | Программа ИИ с открытым кодом для автоматического обнаружения и обводки отдельных клеток на снимках микроскопии. «cyto2» — нейросетевая модель, обученная на изображениях тела клетки. |
| занятость (occupancy) | Доля площади изображения, занятая клетками (0 = пусто, 1 = полностью). Измеряется без обводки каждой клетки, по закономерностям яркости пикселей. |
| Отсу | Алгоритм автоматического нахождения порога яркости между пикселями клеток и фона. |
| Кэнни | Алгоритм обнаружения краёв (границ) объектов; здесь считает края клеток как косвенный показатель плотности. |
| FOV / поле | Один снимок через микроскоп. 990 полей = 990 фотографий. «Поле зрения» — область, видимая через объектив в одном кадре. |
| сегментация | Определение, какие пиксели изображения принадлежат каждой клетке, и обводка её границы. «Инстанционная сегментация» = каждая клетка обводится отдельно. |
| blob | Альтернативный метод поиска клеток как округлых заполненных областей на изображении без нейросетевой сегментации. |
| уменьшение масштаба (downscale) | Уменьшение числа пикселей изображения перед обработкой; стандартизирует размер клеток в пикселях и ускоряет анализ. |
| эксцентриситет | Метрика формы клетки (0–1): 0 = идеальный круг, 1 = линия. Выше = более вытянута. |
| соотношение осей | Отношение длиннейшего диаметра к кратчайшему вписанного в клетку эллипса. 1,0 = круг; больше = вытянутее. |
| солидность | Метрика формы (0–1): насколько «компактен» контур клетки. Почкующаяся клетка имеет меньшую солидность (почка нарушает гладкость границы). |
| доля почкования | Доля дрожжевых клеток, активно делящихся в момент съёмки, — видна как небольшая «почка» (выступ) на материнской клетке. Выше = активнее деление. |
| 100× / 10× | Увеличение: объекты выглядят в 100 или 10 раз крупнее реального размера. При 100× видны отдельные клетки (~5–8 мкм); при 10× — только плотность популяции. |
| HEIC | Формат фотографий iPhone. Здесь: снимки через окуляр микроскопа смартфоном. |
| слепая LLM | ИИ-модель (Claude Opus 4.8) оценивала каждый снимок, не зная, из какого канала он взят, — это исключает предвзятость из-за знания ожидаемого результата. «Слепой» = оценщик не знает принадлежности к группе. |
| агностичный к группе | Метод анализа не использует и не видит метки каналов до самого последнего шага группировки измерений. |
| конечная точка (endpoint) | Одно измерение, взятое в один момент времени (не временной ряд). Не показывает, как клетки менялись во времени, — только их состояние в момент снимка. |
| смена знака (sign-flip) | Направление эффекта поменялось на противоположное между условиями (цикл 1 показал порядок, обратный циклам 2–3). |
| Whi5 / G1-сайзер | Whi5 — белок-тормоз деления. Механизм G1-сайзера позволяет клетке «измерить» свой размер перед делением. Клетки, прошедшие контрольную точку «Start» маленькими, производят мелких дочерних клеток. |
| Start | Молекулярная «точка невозврата» клеточного цикла дрожжей: после неё клетка обязана начать деление. Прохождение Start маленькой клеткой = более мелкие дочерние клетки. |
| G2/M | Фазы клеточного цикла: G1 (рост) → S (копирование ДНК) → G2 (подготовка) → M (деление). «Остановка в G2/M» = клетки застряли прямо перед делением; выглядят как готовые к делению (с почками), но не завершают его. Трудно отличить от быстрого деления на одиночном снимке. |
| тайм-лапс | Многократная съёмка одних и тех же клеток на протяжении часов (например, каждые 5 мин); создаёт «видео» деления. Прямое измерение скорости деления, в отличие от одиночного снимка. |
| OD600 / время удвоения | OD600 = мутность жидкости при свете 600 нм. При размножении клеток жидкость мутнеет. Время удвоения = время, за которое численность клеток удваивается. Более быстрое деление = меньше время удвоения. |
| стационарная фаза | Когда питательные вещества исчерпаны, дрожжи перестают делиться и переходят в состояние покоя. Такие клетки мельче и могут имитировать предсказанное уменьшение CH19. |
| покоящиеся | Отдельные недепящиеся клетки в спящем состоянии. Меньше активно растущих. |
| кинетический / морфологический | Кинетический эффект = влияние на скорость деления клеток (не на их количество). Морфологический эффект = влияние на форму или размер клеток. |
| краситель жизнеспособности | Краситель, позволяющий отличить живые клетки от мёртвых под микроскопом (например, метиленовый синий: живые обесцвечивают его, мёртвые остаются синими). В данной партии не применялся. |
| a priori (априори) | Известное или предсказанное до эксперимента; CH17 «априори неизвестен» = прогноза для него заранее не было. |
| конфаунд | Неконтролируемый фактор, помимо тестируемого воздействия, который мог бы объяснить наблюдаемое различие (разная фокусировка, разведение или освещение между каналами). |
| морфометрия | Количественное измерение формы, размера и геометрии клеток (площадь, вытянутость, округлость). |
