# Протокол эксперимента: исследование Saccharomyces cerevisiae в гиперболическом поле

**🌐 Language / Язык:** [English](experiment_protocol_en.md) · **Русский**

## Установка

- Модельный организм: *Saccharomyces cerevisiae* (сухие дрожжи Dr. Oetker, 7г, партия L329 M68)
- Для каждого условия готовились два типа среды:
  - **N** — нейтральный раствор (базовая ростовая среда)
  - **P** — питательный раствор (обогащённая ростовая среда)
- Образцы распределялись по 4 канальным условиям:
  - **CH0** — контроль, без воздействия поля
  - **CH17** — гиперболическое поле, канал 17
  - **CH19** — гиперболическое поле, канал 19 (ускорение времени)
  - **CH21** — гиперболическое поле, канал 21 (замедление времени)
- Длительность облучения: 80 минут (1ч 20мин) за сессию
- Тип ёмкостей: чашки Петри
- Условия: подвал (−1 этаж), полная темнота во время облучения
- Температура: 10°C (зона облучения в подвале); 18°C (лаборатория на 3-м этаже)
- Датчики среды: цифровой DHT11 (температура + влажность) рядом с каждым образцом; фоторезисторы для контроля освещённости

## Привязка каналов

| Канал | Семантика | Прецедент в исследовании плазмы (Исследование Плазмы Крови, osf.io/8q42f) |
|-------|-----------|---------------------------------------------------------------------------|
| **CH0 / контроль** | Без поля, базовый уровень | Базовый уровень (исследование плазмы крови) |
| **CH17** | Неизвестный эффект (H7) | Не тестировался в исследовании плазмы |
| **CH19** | Ускорение времени | Быстрое формирование сгустка + лизис в плазме |
| **CH21** | Замедление времени | Плотный, медленный сгусток в плазме |

## Циклы эксперимента (биологические реплики)

Проведено три независимых цикла эксперимента:

| Цикл | Метка | Описание |
|------|-------|----------|
| 1 | set 001 | Первый пакет облучения по всем каналам |
| 2 | set 002 | Второй пакет облучения (биологическая реплика) |
| 3 | set 003 | Третий пакет облучения (биологическая реплика) |

Наборы 001/002/003 являются основной единицей реплик для статистического анализа. Каждый цикл — отдельное событие облучения со свежеприготовленными образцами.

## График наблюдений

| Точка времени | Действие |
|---------------|----------|
| До облучения (t=0) | Фотография + микроскопия |
| Сразу после (~80 мин) | Фотография + микроскопия |
| 3ч после воздействия | Фотография |
| 6ч после воздействия | Фотография |
| 12ч после воздействия | Фотография + микроскопия |
| 24ч после воздействия | Фотография + микроскопия + окрашивание |
| 48ч после воздействия | Фотография + микроскопия + окрашивание |

## Микроскопия

- Инструмент: световой микроскоп с мощной светодиодной подсветкой
- Захват изображений: смартфон через окуляр, **формат HEIC**
- Режим съёмки: точечная фотография (не тайм-лапс)

| Объектив | Цвет кольца | Увеличение | Применение |
|----------|-------------|------------|------------|
| Белое кольцо | белый | 100× | Морфология и подсчёт клеток |
| Жёлтое кольцо | жёлтый | 10× | Обзорный снимок поля (занятость/текстура; подсчёт клеток при этом увеличении не применим) |

Примечание: сравнения должны проводиться только внутри одного уровня увеличения (100× с 100×, 10× с 10×).

## Анализ жизнеспособности (зарегистрированный протокол)

**Окрашивание метиленовым синим:**

1. Приготовить раствор для окрашивания: 0,1 мг/мл метиленового синего в 2% дигидрате цитрата натрия.
2. Смешать 100 мкл клеточной суспензии + 100 мкл раствора для окрашивания.
3. Инкубировать 5 минут при комнатной температуре.
4. Нанести на предметное стекло и снять под микроскопом.
5. Оценить клетки:
   - Мёртвые клетки: окрашиваются синим (не восстанавливают краситель)
   - Живые клетки: остаются неокрашенными (ферментативно восстанавливают краситель)
   - Почкующиеся клетки со слабым синим оттенком: считать живыми

> **Важная оговорка:** Это *зарегистрированный* протокол жизнеспособности. **Первый проанализированный пакет микроскопии (09.06.2026, 990 полей, циклы 001–003) окрашивание НЕ использовал**. Синий оттенок на тех изображениях — от среды и светодиодной подсветки, а не от метиленового синего. Этот пакет отражает только **плотность клеток**, а не жизнеспособность. Окрашивание, измерения OD600 и данные о ферментации остаются в работе.

## Данные

- 3 цикла эксперимента (биологические реплики): 001, 002, 003
- 990 полей микроскопии проанализировано в первом пакете снимков (09.06.2026)
- 4 канальных условия: CH0 (контроль), CH17, CH19, CH21
- 2 кофактора среды: N (нейтральная), P (питательная)
- 2 увеличения: 100× (белый объектив), 10× (жёлтый объектив)
- Формат изображений: HEIC (исходный), PNG/JPG (обработанный)

## Провальные / исключённые образцы

- Образец **2-0-P1**: провальная группа — образец пролит / отсутствует (тире в журнале подтверждены корректными). Исключён из анализа.
